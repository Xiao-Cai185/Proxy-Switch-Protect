# Proxy Protect 隐私说明

本扩展的全部数据仅保存在你本机浏览器的 `chrome.storage` 中，不会上传到任何服务器。

## 会读取或处理的信息

- 你手动填写的代理地址、端口与（可选）HTTP 代理用户名密码。
- 守护域名、期望国家/IP 段，以及记事本中的邮箱、别名、常用地区与备注。
- 为检测落地 IP，扩展会通过**当前浏览器代理**向你启用的检测源（如 IP.SB、ipwho.is）发起请求；这些公共接口会看到当时的出口 IP。
- 若开启习惯统计，会在本机记录「访问过的可注册域名 × 落地国家 × 日期」。

## 不会做的事

- 不建立账号、不同步云端、不收集浏览历史全文。
- 不把记事本、代理凭据或访问记录发送给开发者。

卸载扩展或在「设置」中「清除全部数据」即可删除本地记录。导出的 JSON 备份含敏感信息，请自行妥善保管。
