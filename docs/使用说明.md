# Proxy Switch Protect 使用说明

## 1. 安装

构建后在 `chrome://extensions` 以「加载已解压的扩展程序」方式选择 `dist/`。首次安装会请求代理、存储、网络拦截等权限，均用于本机切换代理与守护站点，数据不离开浏览器。

## 2. 添加并切换代理

1. 点击工具栏图标 → 右上角「设置」。
2. 在「代理档案」中新增：填写名称、协议、服务器、端口。
3. HTTP / HTTPS 代理可填用户名密码；SOCKS4/5 认证被 Chromium 限制，界面会禁用该字段。
4. 回到 Popup，点击档案即可切换。角标显示落地国家代码（如 `SG`）；检测中为 `…`，失败为红色 `!`。

内置两项：

- **直连**：不走任何代理。
- **系统代理**：交还控制权，跟随系统或其他程序。

若提示「代理设置由其他扩展或策略控制」，请先关闭冲突的代理类扩展。

## 3. 为敏感网站开启守护

以 ChatGPT 长期使用新加坡 IP 为例：

1. 「守护规则」→ 新增：域名填 `chatgpt.com`（自动包含全部子域）。
2. 期望落地国家选择「新加坡」。
3. 可选：填写期望出口 IP 段（CIDR），以及记事本中的邮箱、账号别名、常用地区。
4. 保存并保持「启用」。

之后只要当前落地不是新加坡（或无法确认落地 IP），访问 chatgpt.com 会被拦截。切回正确节点并检测通过后，拦截页会自动跳回原网址。

## 4. 拦截页上能做什么

- **重新检测**：你已切回正确节点后点此验证。
- **打开设置切换代理**：跳到扩展设置页更换档案。
- **强行放行 N 分钟**：二次确认后临时放行该站点，到期自动重新锁定。仅在你明确了解风险时使用。

## 5. 记事本与习惯建议

- 「记事本」可单独为某域名记邮箱 / 常用地区，不必立刻启用守护。
- 正常浏览时，扩展按天记录「域名 × 落地国家」。某站在统计窗口内几乎总是同一国家，会提示一键绑定守护。
- 可在「设置」关闭统计或通知。

## 6. 备份

「设置 → 数据管理」可导出 / 导入 JSON。备份含代理凭据与邮箱备注，请当作敏感文件保管。
