# Proxy Protect

Chrome / Edge（Manifest V3）浏览器扩展：在浏览器内切换 HTTP / SOCKS4 / SOCKS5 代理，检测实际落地 IP 与国家旗帜，并为敏感网站（如 ChatGPT）绑定「期望落地地区」。当前出口 IP 与绑定不符时，**先拦截再验证**，避免账号因 IP 漂移触发风控。

## 核心能力

- **代理档案**：HTTP / HTTPS / SOCKS4 / SOCKS5，支持直连与系统代理；HTTP(S) 代理支持用户名密码。
- **落地 IP 检测**：多源串行降级，Popup 显示 IP + 国旗，工具栏角标显示国家代码。
- **域名守护（fail-closed）**：切换代理、重启浏览器、检测失败时，受保护域名一律先拦截；只有检测结果与当前代理指纹一致且国家/IP 段匹配才放行。
- **拦截页**：对比当前落地 vs 期望地区，展示记事本（邮箱、常用地区、备注），检测恢复后自动跳回原网址。
- **记事本**：为每个域名记录账号邮箱、别名、常用 IP 地区与自由备注，仅存本机。
- **习惯学习**：按天统计「域名 × 落地国家」，稳定习惯可一键创建守护绑定。

> Chromium **不支持带认证的 SOCKS5**。若代理需要用户名密码，请用 HTTP 代理，或用 gost / privoxy 在本地转成无认证 SOCKS / HTTP。

## 加载到浏览器

1. 执行 `npm run build`。
2. 打开 Chrome / Edge → `chrome://extensions`（或 `edge://extensions`）。
3. 打开「开发者模式」。
4. 「加载已解压的扩展程序」，选择本仓库的 `dist/` 目录。

## 推荐首次配置

1. **设置 → 代理档案**：新增节点（例如新加坡 SOCKS5）。
2. 在 Popup 中点选该档案，确认顶部状态卡显示正确的落地国家与旗帜。
3. **设置 → 守护规则**：为 `chatgpt.com` 绑定期望地区 `新加坡（SG）`，并在备注中写下账号邮箱与常用地区。
4. 故意切到其他国家节点，再打开 chatgpt.com——应看到拦截页；切回新加坡并重新检测后，页面会自动返回。

## 安全模型

任何「不确定」状态（检测中、失败、刚切换代理、浏览器刚启动）下，守护域名默认拦截。拦截由 `declarativeNetRequest` 持久规则执行，不依赖后台脚本是否存活。全部配置与备注只写 `chrome.storage`，不会上传。
